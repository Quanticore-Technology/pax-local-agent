The agent is running as a background service and will auto-start every boot. You should see "Online" in the dashboard within a few seconds.

Verify

curl http://127.0.0.1:9876/health

Common operations

  • Re-run setup (e.g. PAX got a new IP):
    sudo /usr/local/bin/pax-agent setup
    Then: sudo launchctl kickstart -k system/com.gonails.paxagent
  • View logs:
    tail -f /Library/Logs/GoNails/PaxAgent/agent.log
  • Uninstall:
    sudo bash /usr/local/share/pax-agent/uninstall.sh
