GoNails PAX Agent

This installer sets up the on-prem relay agent that connects your salon's PAX A920 payment terminal to the GoNails cloud POS.

What this installs

  • Binary: /usr/local/bin/pax-agent
  • Service: com.gonails.paxagent (auto-starts at boot)
  • Config: /Library/Application Support/GoNails/PaxAgent/
  • Logs: /Library/Logs/GoNails/PaxAgent/

Before you continue

Have ready, from the cloud dashboard (Settings → Payment Device → PAX Agent → Generate Token):

  1. Office ID
  2. Agent ID
  3. Agent Token (starts with pat_)
  4. The PAX A920 device's IP on the salon LAN

Administrator privileges are required.
